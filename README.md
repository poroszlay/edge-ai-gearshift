PC-s szabályreferencia szintetikus menetszakaszok címkézéséhez.

Python 3.13.5 alatt ellenőrizve; külső csomag és hardver nem szükséges.
A repository gyökerében:

```bash
python3 -m unittest discover -s tests -v
```

A használatot, az adatmezőket, a hibastátuszokat és az #1 issue elfogadási
ellenőrzéseit a [szabályreferencia szerződése](docs/rule-reference.md) írja le.
A [közös adatszerződés](docs/data-contract.md) továbbra is irányadó.
